# Linking / Transition Words Educational Web App

This is an interactive educational web application designed to help users learn and master Linking and Transition Words for academic writing.

## 🚀 Features & Components

The web application consists of several interactive and educational components:

1. **Header & Navigation (`index.html`)**
   - Features a clean and responsive navigation bar.
   - Provides quick links to different sections of the learning materials.

2. **Educational Materials / Cheat Sheet (`index.html` & `style.css`)**
   - Explores various categories of transition words based on academic guidelines (e.g., _Addition, Contrast, Cause & Effect, Exemplification, and Summarizing_).
   - Includes clear explanations and proper academic example sentences.

3. **Interactive Practice / Quiz Section (`quiz.html` & `questions.js`)**
   - An interactive quiz module to test the user's understanding of transition words.
   - Dynamic question loading and instant score calculation using JavaScript.

4. **Visual Assets (`profil.png`)**
   - Includes illustration/profile assets used across the web pages to enhance user interface (UI) and user experience (UX).

5. **Footer**
   - Contains mandatory project attribution and institutional academic credentials as required by the course guidelines.

## 💻 How to Run Locally

Follow these simple steps to run this website locally on your computer:

### Prerequisites

Make sure you have a modern web browser installed (such as Google Chrome, Mozilla Firefox, or Microsoft Edge). No complex backend server is required since this is a pure static frontend project (HTML, CSS, JavaScript).

### Step-by-Step Instructions

1. **Download or Clone the Project**
   - Extract all project files (`index.html`, `quiz.html`, `style.css`, `questions.js`, and assets) into a single local folder on your computer.

2. **Open with a Local Development Server (Recommended)**
   - Open the project folder using **Visual Studio Code (VS Code)**.
   - Install the **Live Server** extension in VS Code if you haven't already.
   - Right-click on `index.html` and select **"Open with Live Server"**.
   - Your default browser will automatically open the web app at `http://localhost:5500` (or a similar port).

3. **Alternative Method (Direct Browser Open)**
   - Double-click directly on the `index.html` file, and it will open in your web browser.
     _(Note: Using a local server like Live Server is recommended to ensure all JavaScript modules and assets load smoothly without CORS restrictions)._
